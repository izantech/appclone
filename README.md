# AppClone

Native macOS utility for running multiple copies of the same app side by side.

[**Download AppClone for macOS**](https://github.com/izantech/appclone/releases/latest/download/AppClone.dmg)

Requires macOS 14.0 or later. Notarized by Apple.

## What it does

AppClone creates fully independent copies of an installed app — each with its own bundle identifier, data containers, login items, and badge — so you can run multiple Slacks, multiple browsers, or multiple of any macOS app side by side without them stepping on each other.

- **Full clone** — a separate `.app` bundle with its own identity, isolated data, and badged icon.
- **Launch profile** — a reusable shortcut that runs the original binary directly (shares data with the original).
